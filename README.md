# Familia Andino Home Solutions

Premium black-and-gold responsive website for Familia Andino Home Solutions LLC.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation
- `assets/` — logo and visual assets

## Deploy
Upload the project to Vercel. The existing custom domain can stay connected to this project.

## Notes
The contact form uses `mailto:` so submissions open the visitor's email client. For a true web form, connect Formspree, Resend, or another form/email service later.
